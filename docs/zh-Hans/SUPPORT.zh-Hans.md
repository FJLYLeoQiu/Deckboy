# 帮助与社区

Deckboy 是用于现场视频播放和演出控制的自由开源软件。无论你是程序员、第一次操机，还是正在设法把一路较真的信号送到屏幕上，都欢迎来到这里。

## 怎样写一份有用的缺陷报告

请写明 Deckboy 版本、操作系统、CPU/GPU、信号路径（例如：摄像机 → Deckboy → NDI → 接收端）、预期结果、实际结果，以及复现步骤。日志和截图会有帮助。

**保护这场演出。** 在附加日志、截图或演出文件之前，请去掉客户名称、凭据、私有 IP、敏感网址、推流密钥，以及受许可或机密的媒体。不要在公开 issue 中发布密码或安全细节。

## 开门之前

Deckboy 由社区维护，不是有人值班的紧急支持服务。GitHub 的 issue 和讨论不会被实时值守，也不承诺响应时间。正式演出前，请用你的真实硬件和信号链路测试该构建，并准备好已知可用的备用方案。

## 彼此善待

提问时大方，回答时清楚，尊重各种经验水平的操机员。欢迎建设性的批评和缺陷报告。人身攻击、骚扰，以及分享别人的演出隐私，都不可以。
