# Deckboy 简体中文使用说明

本文说明如何安装 Deckboy、把界面切换为简体中文，以及本汉化包覆盖了哪些内容。完整功能手册仍以英文 [MANUAL.md](../../MANUAL.md) 或[在线手册](https://utopian-academy.github.io/Deckboy/manual.html)为准。产品介绍见 [README.zh-Hans.md](../../README.zh-Hans.md)。

- 上游版本：Deckboy **0.99.427**
- 原仓库：<https://github.com/Utopian-Academy/Deckboy>
- 原版提交：`5da84439b112bca9461d20b71f0e46e4e4b733aa`（2026-11-12）
- 默认界面语言仍是英语，简体中文通过语言选择使用，不会取代英文。

本仓库是非官方简体中文本地化，不是官方发行版。完整来源、许可与测试记录见仓库根目录的 [NOTICE.zh-Hans.md](../../NOTICE.zh-Hans.md) 与 [NOTICE.md](../../NOTICE.md)。

## 1. 安装与下载

到 [GitHub Releases](https://github.com/Utopian-Academy/Deckboy/releases/latest) 下载对应平台的安装包或便携包：

| 平台 | 安装包 | 便携版 |
|---|---|---|
| Windows | `…-windows-x64-setup.exe` | `…-windows-x64.zip` |
| macOS（Apple Silicon） | `…-macos-arm64.dmg` | `…-macos-arm64.zip` |
| macOS（Intel） | `…-macos-x86_64.dmg` | `…-macos-x86_64.zip` |
| Linux | `…-x86_64.AppImage` 或 `…-x86_64.flatpak` | `…-linux-x86_64.tar.gz` |

也可用包管理器：

```powershell
# Windows (Scoop)
scoop bucket add deckboy https://github.com/Utopian-Academy/scoop-deckboy
scoop install deckboy/deckboy
```

```sh
# macOS (Homebrew)
brew install --cask utopian-academy/deckboy/deckboy
```

**首次打开被系统拦截时：**

- macOS：若提示应用已损坏，执行  
  `xattr -dr com.apple.quarantine /Applications/Deckboy.app`  
  并从 `.dmg` 安装到「应用程序」，不要从「下载」直接运行。
- Windows：SmartScreen 提示时，选「更多信息 → 仍要运行」。
- Linux AppImage：`chmod +x` 后运行，需要 Ubuntu 22.04 或更新版本。

NDI 需单独安装 NDI 运行时；SDI 需兼容的 Blackmagic 硬件与 Desktop Video。Office 幻灯片转换需要本机上的 PowerPoint、Keynote 或 LibreOffice。

### 在已安装的 Deckboy 上使用本汉化

本仓库是在上述提交上改过的源码。你可以用以下任一方式让简体中文生效：

1. **用本源码自行编译**（见 [CONTRIBUTING.md](../../CONTRIBUTING.md) 的 Building 一节），编译产物会带上更新后的 `data/lang/zh-Hans.tsv`。
2. **只替换语言包：** 把本源码中的 `data/lang/zh-Hans.tsv` 复制到已安装 Deckboy 的 `data/lang/`（或应用包内对应位置）并覆盖同名文件，然后重启 Deckboy，再在设置里选择「简体中文」。覆盖前请先备份原文件。
3. 手机遥控器的中文随 `data/web/remote.html` 与 `data/web/remote.js` 一起提供；若只更新了 tsv，手机页仍可能是英文，除非浏览器语言为中文且这两个文件也已更新。

不要改命令名、协议词或 `.deckboy` 演出文件格式。许可证全文仍在 [LICENSE](../../LICENSE)。

## 2. 切换为简体中文

1. 启动 Deckboy。
2. 打开 **设置（Settings）→ Language（语言）**。
3. 选择 **简体中文**。界面立即切换，无需重启。
4. 也可用远程命令：`LANGUAGE zh-Hans`。查询当前语言：`LANGUAGE`。改回英文：`LANGUAGE en`。

语言选择器旁的 **Help!** 按钮始终显示为英文，并会立刻把界面恢复为英语，以免选到自己看不懂的语言后被卡住。

中文界面优先使用系统中已有的中文字体（如微软雅黑 `msyh.ttc`、宋体、苹方、Noto Sans CJK）。若本机完全没有这些字体，部分文字可能显示为空框；设置页会提示，而不是让你自己猜。

## 3. 基本操作

- **卡座（Deck）** 就是一条播放列表。VJ 模式可同时使用两个卡座。
- **Cue** 是列表里的一条：视频、静帧、幻灯片、摄像机、NDI、测试图、下方字幕条、音频等，操作方式相同。
- **TAKE** 把当前选中的 cue 送到观众（节目输出）。空格键通常用于播放/暂停，Enter 用于 TAKE（以手册和当前键位设置为准）。
- **黑场（BLACKOUT）** 立刻切黑画面；演出在下面仍继续运行。
- **走带** 控制播放、暂停、停止、循环和保持。
- 启动画面可选择 **EXAMPLE SHOWS（示例演出）**，按 cue 上的注释练习。示例演出的 cue 注释本身仍为英文。
- 完整键位、输出、远程控制等见英文手册第 1–22 章，尤其是 [21a. Languages](../../MANUAL.md#21a-languages)。

## 4. 有意保留英文的词

项目规定：行业里本来就用英文的词，界面里也保持英文，这样在不同国家的控制台上都能上手。例如：

TAKE、PROGRAM、NDI、SRT、OSC、RTMP、RTMPS、Art-Net、sACN、Syphon / Spout、DeckLink、YouTube、Twitch、vMix API、HAP、DATAMOSH、GO、DASH、LIVE 等。

远程协议命令本身（如 `LANGUAGE`、`OUTPUT`、`WARP GRID`）也不翻译，以免脚本和 Companion/Stream Deck 映射失效。本汉化遵循这些规则。

「卡座」是 Deckboy 里 Deck 的界面译名（与词库中 `Deck {n}` → `卡座 {n}` 一致），不要和 DeckLink、HyperDeck、Stream Deck 等产品名混淆。

## 5. 本汉化覆盖范围

已覆盖：

- 主程序几乎全部会画到屏幕上的界面字符串：按钮、菜单、设置、检查器、提示（toast）、错误与多数远程命令反馈。简体中文词库由原来约 2336 条增至约 3508 条；按项目自带审计（并对 C 字符串转义做了还原）计算，运行时绘制字符串覆盖率约为 **100%**（官方审计工具在未还原 `\xNN` 字面量时显示约 **99.7%**，余下为源码转义与运行时字符串不一致的假缺失，如 `NDI® NETWORK`，词库中已有正确条目）。
- 修正了原词库中的若干术语错误，例如把「Deck」误译成「甲板」「一副牌」，以及「播放台」与「卡座」不统一等问题。
- 安装与使用文档：`README.zh-Hans.md`、本文、`SUPPORT.zh-Hans.md`。英文 README 增加了中文文档入口。默认语言和语言选择机制未改。
- 手机遥控器（`data/web/remote.html` / `remote.js`）：当浏览器语言为简体中文，或地址带 `?lang=zh-Hans` 时，登录说明和常用标签显示中文；TAKE、STOP、GO、REC、LIVE、BLACKOUT、DASH 等控制面词汇保持英文。

未完整翻译或有意保留：

- 完整英文手册 `MANUAL.md`（约 3800 行）及官网 `docs/*.html`、`FEATURES.md`、`CHANGES.md` 等开发/营销文档。请用本文 + 中文 README 入门，深入功能仍读英文手册。
- 课程/教程里的大量英文对白已在原词库中翻译；个别示范演出 cue 注释、示例文件名仍为英文。
- Bitfocus Companion 模块和 Stream Deck 插件在宿主软件中的配置标签仍为英文（宿主通常也是英文界面；命令词必须保持英文）。
- 由代码临时拼接的少量句子（未走 `i18n::format`）可能仍显示英文，例如 `'名称' is not a deck number` 这类动态报错。把它们全部改为格式化模板属于更大范围的代码重构，本次未做。
- `public/` 下较旧的网页原型不是当前桌面控制台，未纳入本次汉化。
- 传统中文词库 `zh-Hant.tsv` 未同步补全。

1. 启动 Deckboy，切换到简体中文。

## 7. 原生 PowerPoint、演讲计时与双总线音频

这些是本仓库功能分支上的非官方扩展，不是上游默认行为。展示目标默认在观众（节目）窗口，可切换到演讲者窗口；设置只在控制台。节目与预听使用不同音频设备和音量；预听设备找不到时保持静音，不会悄悄改到观众 HDMI。PowerPoint 放映在外部窗口中，其声音不经过 Deckboy 混音器。完整 Windows 安装包和便携包会在 Deckboy.exe 同目录附带 deckboy-ppt-helper.exe；缺失则无法原生放映。Deckboy Mini 不含此助手，也没有该控制台功能。完整说明、限制与未验证项见 [PowerPoint演讲计时与音频路由.md](PowerPoint演讲计时与音频路由.md)。
