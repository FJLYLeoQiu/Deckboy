# 原生 PowerPoint、演讲计时与双总线音频

这是 Deckboy 在 `feature/powerpoint-native-playback` 分支上的非官方扩展，不会改动默认分支。界面默认语言仍是英语，可切换简体中文。

## 1. 原生 PowerPoint 放映

**是什么。** 在已安装正版桌面版 Microsoft PowerPoint 的 Windows 上，「PowerPoint 放映」线索通过 `deckboy-ppt-helper`（晚绑定 COM、独立 STA 进程）驱动 PowerPoint 自己的幻灯片放映。下一步 / 上一步调用 `SlideShowView.Next` / `Previous`，因此会推进动画**级进（builds）**，而不仅是整页。对已经打开的同一放映再次 TAKE 会进入下一动画；换另一个文件时只关闭本功能打开的那份文稿。

**不是什么。** 放映画面在 PowerPoint 窗口里。v1 **不会**把该画面合成进 Deckboy 的节目、NDI、录制或推流。如需进节目画面，仍可使用项目里已有的窗口采集线索，这条路径不会自动完成。

**环境。** Windows + 桌面版 Microsoft PowerPoint。不会用 WPS、PowerPoint 网页版或 LibreOffice 走这条路径。其他系统会给出明确提示，仍可使用现有的「导入为静帧」（导出 PDF 再栅格化，会展平动画和切换）。

**安全。** 打开前将 `AutomationSecurity` 设为禁止宏。不会启用、关闭或绕过受保护视图；若文件进入受保护视图，只报告并离开。只关闭本功能打开的文稿。助手进程不会结束 `POWERPNT.EXE`。仅当我们启动了 PowerPoint 且没有其他文稿打开时，才会调用 `Application.Quit`。

**PowerPoint 里的声音和视频。** 它们在 PowerPoint 进程内播放，**不经过** Deckboy 混音器。节目/预听设备、总线音量、静音、录制和推流抽头都不能控制它们。这里没有使用受支持的公开接口把该音频纳入 Deckboy 总线。若观众看的是 PowerPoint 自己的独占全屏窗口，Deckboy 节目输出上的计时浮层**不会**出现在那个全屏窗口上。浮层能否盖住 PowerPoint 独占全屏、以及多屏位置，**尚未在实机上验证，不能保证**。

**如何添加。** 控制台菜单：添加线索 →「PowerPoint 放映（原生，需 Windows 与桌面版 PowerPoint）」。现有的拖放 /「导入幻灯片」仍会展平为静帧，行为未改。

**测试。** `deckboy-powerpoint-protocol-check` 在没有 Office 的情况下检查协议。助手的 `--self-test`（Windows）只测协议。没有 Office 的 runner 或本 Linux 环境**不等于**真实 PowerPoint 验证。

## 2. 演讲计时

**时钟。** 可自定义时长（默认 10 分钟）。默认提醒：剩余 2 分钟、剩余 1 分钟、到时——均可编辑。每条提醒可选用内置声音或本地音频文件（WAV，或捆绑 ffmpeg 能解码的格式），并可在控制台试听。可增删提醒（最多 8 条）。开始 / 暂停 / 继续 / 复位。到 0 之后继续计超时（`+mm:ss` 或 `+hh:mm:ss`）。暂停时间不计入已用/超时。只用单调时钟。每个提醒在一场演讲中只响一次；同一拍跨过多个提醒时只播放最紧急的一个。复位不写场次记录；「新的演讲」会写。场次可导出 CSV。

**设置与展示分离。** 设置/控制面板只在**控制台（控制窗口）**。展示层只显示时间、状态（含临近结束与超时，不只靠颜色）和当前提醒文案。观众展示上不会出现设置按钮、文件路径或控制面板。

**展示目标（默认观众）。**

- **观众（默认）：** 浮层合成进 Deckboy 的**节目（programme）**输出（`window` 与 `stream`）。节目窗口，以及从同一合成画面取出的录制 / 推流 / NDI，三者一致。不会画到演讲者 / 提词 / 多画面输出上。
- **演讲者：** 浮层只合成进 **presenter** 输出，不会进入节目的 NDI / 录制。
- 浮层可拖动；在倒计时画面角落拖动可调整尺寸（观众展示上不会出现设置按钮）。控制台可直接输入像素宽高（例如 `520 200`），也可用 W/H 按钮。锁定布局和复位位置同样在控制台。位置和尺寸会持久化。若恢复时显示器已消失，回退窗口会被限制到可见区域。

**回退窗口。** 当没有对应的节目或演讲者输出时，可用一个桌面工具窗口显示同样的「仅计时」画面。该窗口**不在** NDI、录制或节目流里。操作系统的「全桌面采集」仍可能录到它：那是系统采集，不是 Deckboy 合成。

**与 PowerPoint 的关系。** 可选「随 PowerPoint 放映自动开始计时」；到 0 时**不会**结束或打断放映。

**提醒声音与画面目标相互独立。** 默认路由是**控制端**（控制台 / 界面声音路径）。不会因为画面默认在观众窗口，就把提示音自动混进直播 / 录制。可显式改到观众端；即便如此，仍走控制台声音路径，若系统默认输出就是 PA，则可能与节目共用同一块物理设备——不要假设一定有第二张声卡。非 WAV 的文件声音可能无法试听。

## 3. 节目与预听（下一个素材）音频

**项目里已有、仍保留的能力：** 每个播放列表有节目设备（`audioOutputDeviceName`）和额外发送；**监听（monitor）**设备可以听正在播放的某一个列表的拷贝，并且在设备消失时不会悄悄换成别的设备；现有 AUDITION / PFL 会把该列表从输出拿掉，**不是**下面说的「预听下一个」。

**本次增加的能力。** 一条独立的 **预听 / 下一个素材** 总线：

- 可单独配置**预听音频设备**及其**音量 / 静音**。改预听音量不会改变正式（节目）音量。
- **线索预听**用**第二台引擎**（`previewMediaEngine_`）播放当前选中的视频 / 音频 / 音调线索，同时节目引擎继续播放正在正式播出的素材。它不会走 TAKE，也不会把节目画面切黑。
- 预听 PCM 只打开在已点名的预听设备上。预听引擎的 **audio tap 为空**，这些样本**不会**进入录制、推流或 NDI（那些抽头来自节目引擎）。
- 若点名的预听设备不存在，或只能以系统默认设备方式打开，则预听**保持静音**并提示，**不会**回退到节目 / HDMI / 默认设备。
- 对正在预听的同一条线索执行 TAKE 时，会先停预听，避免同一素材双播和爆音。
- 正式播出的视音频同步仍用现有节目时钟。预听是另一台 SDL 设备；采样率转换按现有后端（SDL）处理。**不保证跨设备严格同步。** 蓝牙往往有额外延迟；免提（HSP/HFP）配置可能是单声道、低码率，不适合当作正式预听。若系统提供 A2DP / 立体声配置，请优先使用。

**节目总线音量。** `programBusVolume`（默认 1.0）只乘在节目引擎的主音量上。预听只用 `previewVolume`。

**覆盖不到的部分。** 原生 PowerPoint 音频（见上）。经 ASIO 驱动的节目声是引擎原有限制，此次未扩展。

## 4. 自动化测试与未做的实机验证

以下测试不依赖 Office、HDMI 或蓝牙：

- `deckboy-speech-timer-check`：默认值（展示目标为观众、提醒路由为控制端、10 分钟、三条提醒）、暂停不计时、复位与新演讲的区别、超时文本、一次性且不叠音、持久化、显示器消失时的位置限制。
- `deckboy-preview-audio-check`：预听设备缺失时保持静音且不会解析成节目设备；节目与预听混音隔离；改变预听增益不影响节目样本；对同一线索 TAKE 会停预听；提醒路由默认控制端。
- `deckboy-powerpoint-protocol-check`：助手协议编解码与文件名判断。

**本环境未做、也不会声称已做：** 真实 Microsoft PowerPoint；计时浮层覆盖 PowerPoint 独占全屏；真实 HDMI 正式播出 + 蓝牙同时预听下一个素材；测量蓝牙延迟；在真实演出中确认带浮层的 NDI/录制；在物理 Windows 电脑上安装包冒烟。这些请在你这边做最终实机验证。

## 5. 控制台用法（短）

1. 在控制窗口打开「SPEECH TIMER」。设置时长、展示目标（默认观众，可改为演讲者）、锁定/复位位置、提醒静音与提醒声音路由。开始 / 暂停 / 复位 / 新的演讲。
2. 设置 → 音频：为播放列表指定节目设备，并设置新的**预听音频设备**。用「线索预听」在预听设备上听选中的下一条，同时当前条目继续在节目设备上正式播放。
3. 在 Windows 上添加 PowerPoint 放映线索，TAKE 打开，再次 TAKE 进入下一动画，上一步退回动画，停止/关闭只结束本功能打开的那份文稿。
